## 一、端口总览（先认三类 MySQL）

| 角色 | 地址 | 部署方式 | 用途 |
|------|------|----------|------|
| **平台主库 + 分层仓** | `localhost:3306` | **本机 MySQL**（默认；Compose **不占**此口） | 业务控制面 + ODS/DWD/DWS/ADS |
| **开源组件辅助库** | `localhost:3307` | Docker `sc_oss_mysql` | OM / DataEase / DolphinScheduler 元库 |
| **业务源测试库** | `localhost:3308` | Docker `sc_source_mysql` | 模拟部门真实库（脏数据探库/采集） |
| **会话/缓存** | `localhost:6379` | 本机 Redis 或 Compose | JWT / 会话 |
| **半结构化** | `localhost:27017` | Docker `sc_oss_mongodb` | 文档 / CDC 落库（按需） |

原则：**3306 = 平台自己的库；3307 = 框架组件库；3308 = 外部源库模拟。三者物理隔离。**

## 二、本机主库 `localhost:3306`（日常必开）

配置来源：`application-dev.yml`、`local.env`、Flyway V58、`compose/init-layer-databases.sql`。

| 库名 | 类型 | 说明 |
|------|------|------|
| `smart_city` | **生产同构主库（本机开发副本）** | 用户/权限/登记/归集台账/治理 `gov_*`；Flyway 管理 |
| `smart_city_ods` | **分层仓 · 原始层** | Kettle 汇聚默认目标 |
| `smart_city_dwd` | **分层仓 · 明细** | 加工融合 |
| `smart_city_dws` | **分层仓 · 汇总** | 指标/主题 |
| `smart_city_ads` | **分层仓 · 应用** | 对外应用表 |

### 连接（开发默认）

| 项 | 值 |
|----|-----|
| Host / Port | `localhost` / `3306` |
| User | `root`（或 `local.env` 中 `MYSQL_USER`） |
| Password | `local.env` 的 `MYSQL_PASSWORD`（**勿提交 Git**） |
| JDBC | `jdbc:mysql://localhost:3306/smart_city?...` |

> **说明**：本机 MySQL/Redis 请自行安装，或用 `compose/oss-stack.yml` 联调栈；生产用 `compose/prod-mid.yml`。

### 检查命令

```powershell
Test-NetConnection localhost -Port 3306
mysql -h127.0.0.1 -P3306 -uroot -p -e "SHOW DATABASES LIKE 'smart_city%';"
```

期望至少出现：`smart_city`、`smart_city_ods`、`smart_city_dwd`、`smart_city_dws`、`smart_city_ads`。

## 三、开源组件库 `localhost:3307`（联调 OM/BI/调度时开）

| 项 | 值 |
|----|-----|
| 容器 | `sc_oss_mysql` |
| Compose profile | `governance` / `bi` / `sched` |
| Root 密码 | `oss_root` |
| 初始化脚本 | `compose/init-oss-mysql.sql` |

| 库名 | 用途 | 对应组件 |
|------|------|----------|
| `openmetadata_db` | 元数据 / 血缘 / 质量 | OpenMetadata `:8585` |
| `dataease` | 仪表板 / 数据集 | DataEase `:8100` |
| `dolphinscheduler` | 工作流 / 任务 | DolphinScheduler `:12345` |

### 检查与启动

```powershell
Test-NetConnection localhost -Port 3307
docker ps --filter name=sc_oss_mysql --format "{{.Names}} {{.Status}}"
docker exec sc_oss_mysql mysqladmin ping -h localhost -poss_root

docker compose -f compose/oss-stack.yml --profile governance up -d
# 需要 BI / 调度时再加 --profile bi / --profile sched
```

## 四、业务源测试库 `localhost:3308`（探库 / 采集 / 共享冒烟时开）

| 项 | 值 |
|----|-----|
| 容器 | `sc_source_mysql` |
| Compose profile | `source` / `governance` / `etl` |
| Root | `root` / `source_root` |
| 库名 | `biz_source` |
| 初始化 | `compose/init-source-mysql.sql`（含脏数据基线） |
| 表 | `ent_master`、`proj_construction` |
| 只读探测账号 | `probe` / `probe_pass`（仅 SELECT） |
| 平台登记常用 | host=`localhost` port=`3308` user=`probe` |

Kettle 容器内会把 `localhost:3308` / `127.0.0.1:3308` 映射为 `source-mysql:3306`（见 `application-dev.yml` `host-map`）。

> **注意**：`:3308` **不是生产库**，仅为联调替身。对接真实部门源库时改登记连接信息，勿写入 Compose 默认。

### 检查命令

```powershell
Test-NetConnection localhost -Port 3308
powershell -File scripts\source_db.ps1 up      # 未起则启动
powershell -File scripts\source_db.ps1 verify  # 校验脏数据基线
```

## 六、未来生产库（政务云对照）

生产 **不使用本机 Compose**；逻辑库与开发对齐（见 D07 §9.5、D13 §七）：

| 生产库 | 位置 | 对应本机 |
|--------|------|----------|
| `smart_city` | VM1 MySQL | `:3306` 主库 |
| OM / DataEase / DS 独立库 | VM1 MySQL（独立 schema） | 本机 `:3307` 三分库 |
| 分层仓 ODS/DWD/DWS/ADS | 同 VM1 或独立数仓实例 | `:3306` 四库 |
| 真实部门源库 | 各委办局生产库 | 本机用 `:3308` `biz_source` **模拟** |
| Mongo / ES / Redis 等 | VM2 等 | Compose storage / cdc |

## 七、按场景检查清单

### A. 只跑平台前后端（最常见）

- [ ] MySQL `3306` 开着，且有 `smart_city` + 四个分层库
- [ ] Redis `6379` 开着
- [ ] `local.env` 中 `MYSQL_PASSWORD` 正确

### B. 数据源探库 / JDBC 采集 / 共享冒烟

- [ ] A 全部通过
- [ ] `3308` `sc_source_mysql` healthy（`scripts\source_db.ps1 verify`）

### C. 元数据 / BI / 调度联调

- [ ] A 通过
- [ ] `3307` `sc_oss_mysql` healthy
- [ ] 对应组件端口：`8585` / `8100` / `12345`
- [ ] `INTEGRATION_ENABLED=true`（见 `local.env`）

### D. 一键探活（Compose 组件）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\oss_health.ps1
```

## 八、一键端口速查

```powershell
@(3306,3307,3308,6379,9200,27017) | ForEach-Object {
  $r = Test-NetConnection localhost -Port $_ -WarningAction SilentlyContinue
  "{0}`t{1}" -f $_, $(if ($r.TcpTestSucceeded) {'OK'} else {'DOWN'})
}
```

| 端口 | 含义 | 日常期望 |
|------|------|----------|
| 3306 | 平台主库 + 分层仓 | **OK** |
| 3307 | 开源组件库 | 联调框架时 OK |
| 3308 | 源库测试 | 采集 / 探库时 OK |
| 6379 | Redis | **OK** |
| 9200 | Elasticsearch | 按需 |
| 27017 | MongoDB | 按需 |

密码以本机 `local.env` 为准；Compose 默认口令（`oss_root` / `source_root` / `probe_pass`）仅限本机联调。
