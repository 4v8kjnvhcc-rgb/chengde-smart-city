# 执行周期管理

## 目的

系统级统一维护 Cron（秒/分/时/日/月/周/[年]），业务定时任务从此处选用，避免各模块手写表达式。

入口：**统一用户管理 → 系统管理 → 系统通用配置 → 执行周期管理**  
Hub Tab：`sys.cfg.cron`（`/analytics/support?tab=sys.cfg.cron`）

## 范围（不含考核评估、智能 BI、服务总线）

| 业务点 | 字段 | 前端 |
|--------|------|------|
| 元数据采集 | `cron_expr` | MetaCollectView |
| 数据质量任务 | `cron_expr` | QualityTaskView |
| ETL/治理任务 | `schedule_cron` | GovernanceTaskListView |
| 融合任务 | `schedule_cron` | GovernanceTaskListView（taskDomain=FUSION） |
| 库表汇聚/接入任务 | `schedule_cron` | StructuredTableWizard / ChannelView |
| 存储生命周期策略 | `schedule_cron` | RcStorageLifecyclePanel / ResourceCenterHub |

搜索同步策略等以只读展示为主，如需改周期一并走本模块。

配套说明：三模块中间件与来源/目标库选源见 [三模块中间件与数据源规划.md](./三模块中间件与数据源规划.md)。

## 数据与 API

- 表：`sys_exec_cycle`（Flyway `V151`）
- API：`/api/v1/system/exec-cycles`（列表/增删改/预览近 N 次执行）
- 选用组件：`ExecCycleSelect.vue`（写入业务侧仍为 Cron 字符串）
