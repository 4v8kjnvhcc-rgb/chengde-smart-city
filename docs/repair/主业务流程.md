- 统一用户管理系统：为通用支撑平台，实现组织、用户、角色、权限、菜单、应用、授权、审计、系统设置等的统一维护管理；
- 任务管理系统：统一管理各业务系统所涉及的任务，包括元数据采集监控、数据汇聚任务、数据治理任务、数据融合任务、数据质量任务、数据指标任务、其他任务等的任务管理、日志监控、调度管理等；
- 数据资产登记管理系统：依次进行项目、系统、数据库、数据表、数据项的登记和管理，再选取有价值的数据表进行数据资产目录的登记和管理，数据标签在数据资产目录处应用；
- 数据资源采集汇聚系统：（1）数据汇聚：对于库表接入的数据源，可直接选取数据资产登记管理系统已经登记的数据库，然后通过单表接入、多表接入、条件接入、整库同步的多种方式接入数据，接入的数据归集到ODS层（数据库：smart_city_ods），对于手动上传的数据，通过手动上传数据从远程FTP服务器或本地选择文件到ODS层（数据库：smart_city_ods），同时也支持非结构化数据接入、半结构化数据接入、应用程序编程接口数据接入、实时数据接入，（2）指标与目录体系构建：对于已接入未加工的原始数据，可通过指标与目录体系构建模块进行数据资源的编目管理、数据资源分类、资源目录注册发布、数据资源目录审批；
- 大数据融合治理平台：（1）元数据管理系统：元数据管理系统的数据源可以选取数据资产登记管理系统已经登记的数据库，元数据读取数据资产登记管理系统已经登记的数据表和数据项，并在元数据管理系统进行维护、采集、监控、版本管理、分析等，并将最新的元数据（包含数据表和数据项）同步给数据资产登记管理系统的数据表和数据项，最好数据资产登记管理系统的数据表和数据项所涉及的业务表和元数据管理系统的元数据（包含数据表和数据项）业务表是同一套；（2）数据治理系统：元数据采集维护后，通过数据治理系统进行治理，治理后的数据放在DWD层（数据库：smart_city_dwd），（3）数据融合系统：通过数据融合系统进行融合汇总，融合后的数据放在DWS层（数据库：smart_city_dws），（4）数据指标系统：将经过治理、融合后的数据进行指标开发，结果数据放到ADS层（数据库：smart_city_ads）,（5）数据目录管理系统：对于加工后的数据(DWD层、DWS层、ADS层)，可通过数据目录管理系统进行资源目录编制（包含数据资源编制、服务资源编制、文件资源编制）、目录注册发布（包含数据资源目录注册发布、服务资源编目注册发布、文件资源编目注册发布）、资源目录审批（包含数据资源目录审批、服务资源目录审批、文件资源目录审批），并通过资源目录门户进行资源申请订阅、资源订阅审批、资源订阅分发。
- 部门数据共享门户：
（1）数据资源采集汇聚系统的指标与目录体系构建模块发布后的目录可在部门数据共享门户展示，（2）主数据平台的大数据融合治理平台的数据目录管理系统发布后的目录可在部门数据共享门户展示，（3）各单位可通过部门数据共享门户进行数据资源的申请和数据交换。数据需求部门进行申请，数据提供部门审核通过后，数据主管部门审核，均审核通过后进行数据交换。
发布到部门数据共享门户的数据资源分为三种形式：库表、接口、文件。
（a）库表：申请审核通过后，由任务管理中心自动创建库表同步任务，定时推送到目标数据库，数据同步任务的执行情况在任务管理系统统一管理，部门管理员可在部门数据共享门户的个人中心查看任务详情；
（b）接口：申请审核通过后，由服务总线自动将原接口进行封装转发，生成token和密钥，部门管理员可在部门数据共享门户的个人中心查看将封装后的接口信息及token、密钥，由服务总线（ESB）进行接口的管理，包括接口运行监控、日志查看、调用次数统计等；
（c）文件：申请审核通过后，部门管理员可在部门数据共享门户的个人中心查看FTP文件服务器上的文件地址。
- 数据供需对接系统：如果在部门数据共享门户没有找到的数据目录或数据资源，各单位可通过数据供需对接系统进行需求的填报，供需对接的业务流程如下图所示。已经通过的数据需求，由数据提供部门通过数据资源采集汇聚系统的指标与目录体系构建模块发布到部门数据共享门户，数据需求部门通过部门数据共享门户进行申请。

- 服务总线：（1）接口开发：（a）数据汇聚时，源业务系统以接口形式提供数据，需通过服务总线将接口数据存放到ODS层；（b）数据资源注册时，数据需求部门需要通过接口形式对接数据，需通过服务总线将库表转为接口；（2）接口转发：部门管理员在部门数据共享门户申请了接口类型的数据资源并审核通过后，由服务总线自动将原接口进行封装转发，生成token和密钥，部门管理员可在部门数据共享门户的个人中心查看将封装后的接口信息及token、密钥，由服务总线（ESB）进行接口的管理，包括接口运行监控、日志查看、调用次数统计等；
- 智能BI平台：在大数据融合治理平台的数据指标系统开发好指标后，将ADS层的库表利用智能BI平台制作成IOC大屏分析展示，制作成的IOC大屏包含基础库统计分析、重点领域统计分析应用、领导决策门户等
- 人口大数据支撑系统：利用大数据归集平台的数据资源采集汇聚系统和主数据平台的大数据融合治理平台的数据归集、治理、融合等能力，基于人口大数据支撑系统进行数据模型构建、数据指标开发；构建好的数据模型和指标通过智能BI平台制作成IOC大屏分析展示；
- 法人大数据支撑系统：利用大数据归集平台的数据资源采集汇聚系统和主数据平台的大数据融合治理平台的数据归集、治理、融合等能力，基于人口大数据支撑系统进行数据模型构建、数据指标开发；构建好的数据模型和指标通过智能BI平台制作成IOC大屏分析展示；
- 宏观经济及工业运行大数据支撑系统：利用大数据归集平台的数据资源采集汇聚系统和主数据平台的大数据融合治理平台的数据归集、治理、融合等能力，基于人口大数据支撑系统进行数据模型构建、数据指标开发；构建好的数据模型和指标通过智能BI平台制作成IOC大屏分析展示；
- 重点领域示范应用支撑系统：利用大数据归集平台的数据资源采集汇聚系统和主数据平台的大数据融合治理平台的数据归集、治理、融合等能力，基于人口大数据支撑系统进行数据模型构建、数据指标开发；构建好的数据模型和指标通过智能BI平台制作成IOC大屏分析展示；
- 考核评估系统：对各部门进行考核评估；
- 业务功能平台：人口、法人、城市部件管理；
