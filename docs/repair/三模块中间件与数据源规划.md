# 三模块中间件与数据源规划

## 适用范围

1. 大数据归集平台 · 数据资源采集汇聚 · **数据汇聚接入**
2. 主数据平台 · **数据治理**
3. 主数据平台 · **数据融合系统**

配套：`.cursor/plans/三模块中间件规划_e8d822b8.plan.md`；规格 `docs/superpowers/specs/2026-08-11-etl-ds-only-schedule-design.md`。

## 中间件分工

| 组件 | 角色 | 说明 |
|------|------|------|
| **Kettle Carte** | 执行面（唯一） | 汇聚抽数、治理/融合 KTR 真正跑数；**手动执行直调 Carte** |
| **DolphinScheduler** | 调度/编排面（定时主路径） | 启动=调度上线，停止=调度下线；到期 SHELL 回调平台再调 Carte |
| **sys_exec_cycle** | Cron 字典 | 统一用户管理 → 系统配置 → 执行周期管理；业务侧存 Cron 字符串 |

**二者都要部署，不是二选一。** 不采用 XXL-Job / Kafka 作为这三模块 ETL 引擎。  
**不采用** Spring `@Scheduled` 按业务 Cron 扫表触发汇聚/治理/融合任务。

心智模型：**DS=何时跑；Kettle=怎么跑；执行周期=Cron 字典；数据源弹窗=从哪来/到哪去。**

```text
ExecCycleSelect → schedule_cron
       ↓ 启动定时
DolphinScheduler online
       ↓ 到期
HTTP 回调（token）
       ↓
Kettle Carte
```

## 执行周期

入口：统一用户管理 → 系统管理 → 系统通用配置 → **执行周期管理**（Hub `sys.cfg.cron`）。

| 业务 | 字段 | 前端 |
|------|------|------|
| 库表汇聚/接入 | `schedule_cron` | `StructuredTableWizard` + `ExecCycleSelect` |
| 治理 / 融合任务 | `schedule_cron` | `GovernanceTaskListView` + `ExecCycleSelect` |
| 元数据采集 / 质量 | `cron_expr` | 对应视图 + `ExecCycleSelect` |

## 数据源选择（来源库 / 目标库）

**禁止**在三模块任务配置中写死「来源必须是某库、目标必须是 smart_city_ods/dwd/dws/ads」。

须使用统一弹窗 **「选择数据源」**：

- 左：数据源分类（`gov_meta_source_category`）
- 右：名称 / 版本 / 所属分类 / 提供部门
- API：`GET /governance/catalog/resources-mgmt/bind-sources?sourceKind=META`
- 组件：`platform-frontend/src/components/common/MetaDataSourcePickerDialog.vue`

连接键约定：

- 平台分层物理库：`smart_city_ods|dwd|dws|ads`（兼容旧任务）
- 元数据数据源：`meta:{id}`
- 归集登记源：`ds:{id}`

执行时后端解析为 JDBC，写入 Kettle connection。
