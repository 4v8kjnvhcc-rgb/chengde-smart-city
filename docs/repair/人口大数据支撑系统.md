## 结论摘要

1. **保留现网**：`/analytics/population` 五区 Hub（M152～M174），深链归集 / 治理 / 资源中心 / 目录 / M048；不新建独立人口子系统。
2. **五区内关系**：采集进 → 治理净 → 核心存 → 分流到内部严 / 共享出；禁止旁路核心。
3. **展示**：取消 DataEase；十四模型自研样例表。
4. **ETL**：Kettle + DolphinScheduler；人口域不自建 Spring 扫表。
5. **Hub 已全覆盖五区 Tab**：
   - 采集：挂载 + 多源通道清单
   - 治理：挂载 + 机制 + 校核台账
   - 核心：挂载 + 存储/分区摘要（LEDGER）
   - 内部：挂载 + 双重授权（深链 M048 + 概览）
   - 共享：挂载 / 目录 / 接口·批量台账 / 指标 / 模型
6. **库表骨架**：V190 主题/校核/契约；V191 批量台账。
7. **仍依赖外部、无法在本仓库单独完成**：部门真源对接、物理 ALTER 分区、ESB/前置库生产传输、DWS 查询路径强制数据权。未提交 git。
