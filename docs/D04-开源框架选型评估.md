## 四、分域决策摘要

### 4.1 OpenMetadata（治理域）

- **不 POC，直接定**；qData 因修改版 License 不予采用。
- ES 为 OpenMetadata 与全文检索**共用**，非新增组件。
- 适配工作量：**3～5 人月**（菜单映射、机构权限、审批流、质量规则中文化）。

### 4.2 DataEase（BI 域）

- **不改源码 + iframe 嵌入** + API/JWT SSO；GPL 不传染。
- Plan B：法务否决时 2 天内切换 Superset（Apache 2.0）。
- 适配工作量：**1.5～2.5 人月**（40 模型页挂接 + 大屏）。

### 4.3 Canal / SeaweedFS / DolphinScheduler

- **Canal** 替代 Debezium+Kafka，M060 专用，≤1GB。
- **SeaweedFS** 替代 MinIO，S3 网关，Apache 2.0。
- **DolphinScheduler** Standalone，M098/M100/M110。

## 五、统一门户集成架构

```
统一门户（Vue3 自研，JWT+双因素）
├── 数据治理 → 代理 OpenMetadata（菜单名映射 V3.0）
├── 智能 BI / 分析模型 / 领导门户 → iframe DataEase
├── 调度管理 → 代理 DolphinScheduler
├── 服务总线 → M214 代理/深链 AEAI ESB
├── 业务功能（供需/考核/资产/人口法人…）→ 纯自研页
└── 禁止甲方直接访问框架原生 URL
```
