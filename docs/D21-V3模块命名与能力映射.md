# D21 · V3.0 模块命名与能力映射

> 权威目录：`catalog/v3-catalog.normalized.json`  
> Cursor 规则：`.cursor/rules/v3-module-naming.mdc`、`.cursor/rules/data-layer-process-vs-resource.mdc`  
> 实用化：`D20-模块实用化与交互验收标准.md`  
> 架构口径：`D07` §9.3.1

## 1. 硬原则

1. **V3.0 = 项目基本需求**；其子系统/模块名称 = 门户 Hub 侧栏与页标题。
2. 子能力须先对照**已实现框架**挂载，禁止平行假实现。
3. 对齐命名后，按 D20 做登记对象选择、真实执行、中文状态、可监控。
4. **过程数据 ≠ 目录资源**：治理过程层默认不进门户；目录挂直通源资源或融合主题/专题资源。

## 2. 过程 / 资源分层（与融合·质量改造对齐）

| 层级 | 落库 | 质量门禁用途 | 目录 |
|------|------|--------------|------|
| 源层 | 登记源 / ODS | 直通共享前稽核 | 可编目 |
| 过程层 | DWD | 整改与融合输入 | 默认不进门户 |
| 资源层 | DWS / ADS | 加工共享前稽核 | 可编目 |

- **治理**：单表/规则向 → 过程数据为主  
- **融合**：多表成基础库/主题库/专题库 → 资源数据为主  
- **融合「数据清洗」**：多表加工中的清洗组件，**不是**治理单表整改的别名  

## 3. 数据融合系统

| V3.0 | 路由 | 实现 |
|------|------|------|
| 数据仓库建设 | `mSub=warehouse` | FusionModelView；物理绑定默认倾向 DWS |
| 数据融合处理 | 侧栏三级；`mSub=script\|clean\|schedule\|execute\|version` | FusionCapabilityHost |
| 数据融合组件 | `mSub=components` | GovernanceComponentsView（复用） |

| 子能力 | 落地要点 |
|--------|----------|
| 脚本开发 | 分层校验；不成目录资源 |
| 数据清洗 | **仅融合任务**（`taskDomain=FUSION`）：DWD→DWS/ADS；可双表横连；**无组件列表**；与治理任务隔离 |
| 工作流调度 | 仅调度融合任务 |
| 任务执行 | 加工共享 + 融合任务运行 |
| 版本管理 | 脚本发布/回滚 |

## 4. 数据质量管理系统

| V3.0 | qSub | 实用化要点 |
|------|------|------------|
| 数据标准体系 | standards | 标准基线 |
| 质量规则配置 | rule-config | 来源库按源/过程/资源分组 + 目录提示 |
| 数据质量任务 | task-mgmt | 同上；任务绑定即选定稽核层级 |
| 数据质量监控 | monitor | 标明过程层不驱动门户 |
| 数据质量评估 | assess | 评估结果按层级解读 |
| 数据质量分析报告 | reports | 发布门禁只用源/资源层运行 |

执行面：`QualityExecuteService` + `gov_quality_*`；黄金路径共用。

## 5. 数据目录管理系统

| V3.0 | cSub | 落地 |
|------|------|------|
| 资源目录编制 | `resources` | `CatalogResourceView`：强制选登记元数据；拒 DWD；禁直接发布 |
| 目录注册发布 | `publish` | `CatalogRegisterPublishView`：分类 CRUD + 关联/解绑 |
| 资源目录审批 | `approvals` | `CatalogApprovalView`：单条+批量；通过后自动上架/下线 |
| 资源申请订阅 | `subscriptions` | `CatalogSubscriptionView` |
| 资源目录门户 | `portal` | `CatalogPortalView`：表/卡 + 提供方/来源筛选 |

编目对象须满足「资源」判定（直通源或加工 DWS/ADS），见 D07 §9.3.1。

## 6. 非结构数据融合治理平台 / 大数据平台资源中心

对照表见 `.cursor/rules/v3-module-naming.mdc`。

- **非结构化**：侧栏顺序为 **文件资源管理 → 数据分类管理**（对齐 V3 rowIndex 98→99），默认进入 `files`。
- **资源中心**：**数据资产区**为侧栏单入口，四模块用页内 Tab；**数据库存储管理** 5 子能力、**数据库检索查询** 3 子能力（数据全文检索 / 元数据检索 / 数据查询与下载）亦为页内 Tab；其余资源中心管理模块各占侧栏一项。

## 6.1 大数据挖掘分析平台

| 系统 | Hub | 要点 |
|------|-----|------|
| 通用支撑·统一用户 | `analytics/support` → `/system/uum` | V3 七模块名；复用全局身份 |
