## 一、前置条件

| 项 | 要求 |
|----|------|
| Docker Desktop | 已安装并运行 |
| 本机内存 | 建议 ≥32GB；不足时分 profile 启动 |
| 本机 MySQL | `smart_city` 库（端口 **3306**），**不被 Compose 占用** |
| 本机 Redis | 端口 6379 |
| Canal CDC | 需本机 MySQL 开启 `log_bin`（见 §五） |

## 三、启动顺序

```powershell
# 1. 复制环境变量
copy local.env.example local.env
# 编辑 local.env 填入 MYSQL_PASSWORD 与各 OSS URL

# 2. 分波启动（推荐）
docker compose -f compose/oss-stack.yml --profile storage up -d
docker compose -f compose/oss-stack.yml --profile governance up -d
docker compose -f compose/oss-stack.yml --profile bi up -d
docker compose -f compose/oss-stack.yml --profile sched up -d
docker compose -f compose/oss-stack.yml --profile etl up -d
docker compose -f compose/oss-stack.yml --profile cdc up -d

# 或一键（内存充足）
powershell -ExecutionPolicy Bypass -File scripts\oss_up.ps1 -All

# 3. 探活
powershell -ExecutionPolicy Bypass -File scripts\oss_health.ps1

# 4. 后端 + 前端
cd platform-backend
.\mvnw.cmd spring-boot:run "-Dspring-boot.run.profiles=dev"
cd platform-web
npm run dev
```

## 五、Canal 与本机 MySQL

Canal 通过 `host.docker.internal:3306` 连接本机 MySQL。需在 `my.ini` 启用：

```ini
[mysqld]
log-bin=mysql-bin
binlog-format=ROW
server-id=1
```

修改后重启 MySQL 服务。

## 六、门户集成方式（不改开源源码）

| 组件 | 集成模式 | 后端包 |
|------|----------|--------|
| OpenMetadata | REST 代理 | `integration/openmetadata` |
| DataEase | iframe + 嵌入 Token | `integration/dataease` |
| DolphinScheduler | REST 代理 | `integration/ds` |
| Kettle | Carte REST | `integration/kettle` |
| SeaweedFS | S3 API | `integration/storage` |
| Elasticsearch | REST 索引 | `integration/storage` |

配置开关：`app.integration.enabled=true`（见 `application-dev.yml`）。

## 七、生产对照（政务云 VM）

| VM | 规格 | 组件 |
|----|------|------|
| VM1 | 16GB | Nginx、Spring Boot、MySQL、OpenMetadata、DS、Kettle |
| VM2 | 10GB | ES、SeaweedFS、Canal、MongoDB、DataEase、Redis |

生产默认使用 Docker Compose 两机部署（D23：`prod-app` + `prod-mid`）；本 Compose（`oss-stack`）仅作**本机联调加速**，与生产文件分离。
