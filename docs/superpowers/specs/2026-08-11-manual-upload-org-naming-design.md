# 手动上传：组织隔离与命名规范设计

## 背景

大数据归集平台 · 数据资源采集汇聚 · 数据汇聚接入 · 结构化数据接入 · 手动上传数据。

## 范围

1. 列表：删编码列；加归属机构、查询；上传记录并入操作列抽屉；组织隔离。
2. 新建模板：归属机构；目标表 `ods_up_` + 模板中文拼音首字母；可手改。
3. 建表：字段名=表头中文拼音首字母小写；字段注释/表注释=中文。
4. 「同步资产」展示不变（资产名或 `资产#ID`）。

## 隔离

- 部门管理员：仅本机构模板与上传记录；归属机构锁定。
- 超级管理员：全量；可筛选/选择机构。

## 数据

- `ing_upload_template` / `ing_upload_record` 增加 `org_id`（及展示用机构名可联查）。
- 列表 API 按当前用户 org 过滤；超管可传 `orgId`/`keyword`。
