#### 4.1.1 后续对接生产系统（门户嵌入）

> 当前仓库尚未落地 OnlyOffice 业务代码；引擎已在 `.12` 待命。正式对接**不要用** `ds-example`（演示页），由门户 Backend 签发配置、前端嵌入 `DocsAPI.DocEditor`。

**对接前引擎收口（生产态）**

1. 在 `.12` 的 `local.json` **重新开启 JWT**（演示阶段曾临时关闭；secret / header 与上表一致）。
2. 保留现场已验证项：允许 Document Server 访问内网 IP（`allowPrivateIP` / `blockPrivateIP=false`）；nginx `secure_link_secret` 与 `storage.fs.secretString` 一致。
3. 生产可不常开 `ds-example`；演示用 `oo-track-shim` 非正式回调，业务须自建 callback。
4. 巡检 `healthcheck=true` 后再联调。

**标准调用链**

1. 用户在门户点「在线预览/编辑」。
2. 前端向 Backend 申请编辑配置。
3. Backend 生成 `document.key`、可被 `.12` 访问的 `document.url`（文件下载链）、`callbackUrl`（保存回调），并用 `ONLYOFFICE_JWT_SECRET` 签发整份 config。
4. 前端加载 `http://10.10.10.12/web-apps/apps/api/documents/api.js`，执行 `new DocsAPI.DocEditor(...)`。
5. Document Server 按 `document.url` 拉文件；编辑结束 POST `callbackUrl`（status=2 等），Backend 落盘到 Seaweed/`smartcity-docs` 或业务库。

**后端必备能力**


| 能力           | 说明                                               |
| ------------ | ------------------------------------------------ |
| 文件下载 URL     | 须 `.12` **内网可达**（Seaweed 或 Backend 短时签名下载）       |
| 保存回调         | 接收 OO POST，校验后写回对象存储/元数据                         |
| JWT 签发       | config 整体签名；Header=`Authorization`；与引擎 secret 一致 |
| document.key | 每次打开（内容变更后）使用新 key，避免缓存脏读                        |


**前端必备能力**


| 能力    | 说明                                      |
| ----- | --------------------------------------- |
| 嵌入编辑器 | 加载 api.js + DocEditor；抽屉/独立页均可          |
| 入口挂载  | 优先：**非结构数据融合治理 → 文件资源管理**（或附件预览）；勿另起空菜单 |


**网络与安全**

- 浏览器 → `.12`（或经网关反代 Document Server）
- `.12` → 文件下载 URL、callback URL（已允许私网 IP）
- 平台 JWT（`APP_JWT_SECRET`）与 OnlyOffice JWT **两套密钥，勿混用**
- 下载链、回调均须鉴权/短时签名；禁止把 example 当业务网盘

**建议实施顺序**

1. `prod-app.env` 写入 `ONLYOFFICE_*`，引擎恢复 JWT。
2. Backend：签发接口 + 回调接口（先 docx）。
3. 前端：编辑抽屉嵌入 DocEditor。
4. 接到非结构化文件列表「在线预览/编辑」。
5. 扩展 xlsx/pptx、只读预览、版本回写。
