## 一、文档说明

### 1.1 目的与范围

| 项 | 说明 |
|----|------|
| **目的** | ① 对照等保三级与 D02 基线，识别应用层差距 ② 关联 D08 验收用例作为验证证据 ③ 为正式测评提供自查底稿 |
| **范围** | **安全计算环境（应用层）**为主；安全通信网络、区域边界、物理环境、管理制度等标注责任方，本平台仅配合 |
| **不在范围** | 机房物理安全、管理制度全文、主机加固细则（见 §四 配合项） |
| **使用方式** | 开发/测试按「关联 D08 用例」执行验证 → 填写 §三 自评列 → 项目经理汇总 §五 签收 |

### 1.2 责任分工（与 D02 §10.2～10.3 一致）

| 责任方 | 职责 |
|--------|------|
| **开发团队** | 应用层安全功能实现；本表应用层项整改；输出拓扑/架构/数据流图 |
| **运维/甲方** | 主机加固、防火墙/WAF、DB 审计、物理安全、管理制度 |
| **测评机构** | 正式测评与结论 |

### 1.3 自评状态定义

| 状态 | 含义 |
|------|------|
| **符合** | 已实现且 D08 用例 PASS 或可提供测评证据 |
| **部分符合** | 已实现主路径，子项待补或仅设计/待 MS 签收 |
| **不符合** | 未实现或与基线冲突 |
| **待测** | 设计已覆盖，待 MS1/MS2 测试填写 |
| **配合项** | 非应用代码，由运维/管理制度满足 |
| **不适用** | 本期无对应建设内容 |

### 1.4 检查项编号规则

`GB-{域代码}-{序号}`：域代码见 §二 总表「域代码」列。
